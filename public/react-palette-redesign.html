Design notes & open questions

Revision 4. The two holdouts, reworked from the original art's full metaphor: thinking is now a pondering face with a rising thought-dot trail (dots, not a bubble outline — same accent-dot vocabulary the rest of the set already uses) · oops is a proper facepalm again — a tilted hand with scalloped fingertips over the eyes, thumb curl, grimace, and the original's impact lines off the head. Both verified at 120/22/15px, light and dark.

Revision 3. This round: changed my mind is the iconic hollow delta with the heavy bottom edge · thanks is praying hands with the forearms flaring wide at the base (was reading as a pen) · Moloch now has its arms raised on the altar (the recognizable statue) · oops and thinking are redrawn to sit in the same style/weight as the other emotion faces (thinking is a self-contained pondering face; no beard-hand, no floating bubble) · sneer now shows real contempt — angry brows, scrunched nose, a one-sided lip curl.

  • System: every icon is drawn on a 24×24 grid with a 2px stroke, round caps/joins, and small filled dots for accents. Everything is original vector work — no more Noun Project / OpenMoji / openclipart mix, no PNGs, no Cloudinary hotlink.
  • Metaphors kept: the concept of each react is unchanged (bowels is still intestines, concrete is still a cement mixer, llm-smell is still a nose sniffing sparkles). Only the drawing style changed. Exceptions worth flagging: soldier is now a combat helmet (was a tiny guard-with-flag figure that read poorly at 18px), and sneer drops the little “×” badge (the face alone reads better small — easy to re-add).
  • Color & dark mode: icons are currentColor strokes, so they inherit theme color directly — the dark-mode invert(1) filter and per-icon opacity/saturate filters become unnecessary. Overall palette dimming becomes a single shared value (the “icon strength” slider above; production default would replace the current 0.4–1.0 per-icon spread).
  • Fudge filters die: the per-react scale/translateX/translateY corrections in reactions.tsx exist because the source images had inconsistent margins. The new set is optically centered on a shared grid, so all of that can be deleted.
  • Likelihood badges are a uniform type treatment (semibold, same box, same baseline). In this preview they're SVG <text>; for shipping I'd outline them to paths so they're font-independent.
  • Rollout path: once you're happy, I export each icon as a standalone SVG into public/reactionImages/v2/, point reactions.tsx at them, and strip the filter fudges. (Deprecated/uncurated reacts can keep their old art or get redrawn as a follow-up.)
  • Open questions for you:
  • 1. Stroke look ok, or do you want a chunkier/filled style closer to the old Noun Project weight? (I can do a filled-silhouette variant of the same drawings.)
  • 2. Default icon strength — try the slider; I'd propose ~0.72 (current default is 0.4, which is why reacts look so faint today).
  • 3. Any metaphors you want to take the opportunity to change while we're here?
